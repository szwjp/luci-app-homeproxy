# Batch 3（证书体系与工程化收尾）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 服务端证书从内联 `tls.acme` 迁移到 sing-box 1.14 `certificate_provider`；生成配置写入 `$schema`；更新 UI/i18n/README 并升 PKG_RELEASE。

**Architecture:** generate_server.uc 输出 `tls.certificate_provider`（type=acme，字段与现有 UCI 一对一映射）；server.js 在 with_acme 分支增加 1.14 新增的可选输入；client/server 生成 JSON 顶部加 `$schema`；最后做全量回归与发布准备。

**Tech Stack:** ucode、LuCI JS（server.js）、po/i18n、Makefile。

**Spec:** `docs/superpowers/specs/2026-09-02-homeproxy1.14-singbox-1.14-features-design.md`（第 8 节）

## Global Constraints

- 只面向 sing-box ≥ 1.14；不再输出 `tls.acme`。
- UCI 现有 `tls_acme_*` 字段名不变，仅新增可空字段。
- 服务端无 ACME 配置时输出与升级前一致。
- i18n 在批次末统一重扫，避免每任务重复生成 pot。
