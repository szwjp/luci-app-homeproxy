# Batch 2（连接层：TUN dns_mode / UDP NAT / 规则项）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在生成器与 UI 中落地 sing-box 1.14 的 TUN `dns_mode`/`dns_address`、共享 UDP NAT 参数，以及 `source_mac_address`/`source_hostname` 规则项。

**Architecture:** 新全局选项放在 `config` 段（client.js 的 Routing 页），preset/custom 两分支共用读取；生成器只在选项非空时向 TUN/TProxy inbound 与 WireGuard endpoint 写入；`find_neighbor` 为 custom routing 的可选开关。

**Tech Stack:** ucode（generate_client.uc）、LuCI JS（client.js）。

**Spec:** `docs/superpowers/specs/2026-09-02-homeproxy1.14-singbox-1.14-features-design.md`（第 7 节）

## Global Constraints

- 设计文档 7.x 中“routing 段”在本计划落实为 **UCI `config` 段**（即 UI “Routing Settings” tab）；两模式共用读取，避免 custom/preset 重复存储。若此落实与你的预期不符，实施前提出。
- 所有新选项默认空/0：不改变升级前输出。
- TUN `dns_mode` 默认不输出（保持 1.13 派生态），`hijack`/`native` 需用户显式开启。
- 依赖 Batch 1a 的 fixture 运行器与 DNS 规则生成段代码。

### Task B2-1: 全局选项读取与 TUN/TProxy/WireGuard 输出

**Files:**
- Modify: `root/etc/config/homeproxy`（`config` 段追加默认空选项）
- Modify: `root/etc/homeproxy/scripts/generate_client.uc`

**Interfaces:**
- Consumes: `config.tun_dns_mode`、`config.tun_dns_address`、`config.udp_mapping`、`config.udp_filtering`、`config.udp_nat_max`
- Produces: TUN inbound 的 `dns_mode`/`dns_address`/`udp_mapping`/`udp_filtering`/`udp_nat_max`；TProxy inbound 与 WireGuard endpoint 的 UDP NAT 字段（均仅非空时输出）

- [ ] **Step 1: 默认配置加空选项**

`root/etc/config/homeproxy` 的 `config` 段追加：

```
	option tun_dns_mode ''
	list tun_dns_address ''
	option udp_mapping ''
	option udp_filtering ''
	option udp_nat_max ''
```

（list 空值会在 UCI 保存时自然省略；此处只作文档性占位，若 uci-defaults 会写入空 list 则移除该行。）

- [ ] **Step 2: 先写红 fixture**

Create `tests/router/fixtures/client-tun-udp/config/homeproxy`：

```

config homeproxy 'config'
	option routing_mode 'custom'
	option proxy_mode 'tun'
```


- [ ] **Step 3: 运行确认失败**

Run: `sh tests/router/run_fixture.sh client-tun-udp client`
Expected: FAIL（缺少 dns_mode/udp_mapping 等）

- [ ] **Step 4: 读取全局选项**

在 generate_client.uc 的 `udp_timeout` 读取块之后追加：

```js
const tun_dns_mode = uci.get(uciconfig, ucimain, 'tun_dns_mode'),
      tun_dns_address = uci.get(uciconfig, ucimain, 'tun_dns_address'),
      udp_mapping = uci.get(uciconfig, ucimain, 'udp_mapping'),
      udp_filtering = uci.get(uciconfig, ucimain, 'udp_filtering'),
      udp_nat_max = strToInt(uci.get(uciconfig, ucimain, 'udp_nat_max'));
```

- [ ] **Step 5: TUN inbound 输出**

在 TUN inbound push 对象中加入（保持现有键不动）：

```js
		dns_mode: !isEmpty(tun_dns_mode) ? tun_dns_mode : null,
		dns_address: !isEmpty(tun_dns_address) ? tun_dns_address : null,
		udp_mapping: !isEmpty(udp_mapping) ? udp_mapping : null,
		udp_filtering: !isEmpty(udp_filtering) ? udp_filtering : null,
		udp_nat_max: udp_nat_max,
```

- [ ] **Step 6: TProxy inbound 输出**

在 tproxy inbound push 对象中加入：

```js
		udp_mapping: !isEmpty(udp_mapping) ? udp_mapping : null,
		udp_filtering: !isEmpty(udp_filtering) ? udp_filtering : null,
		udp_nat_max: udp_nat_max,
```

- [ ] **Step 7: WireGuard endpoint 输出**

在 `generate_endpoint(node)` 返回对象中加入：


### Task B2-3: UI（client.js）

**Files:**
- Modify: `htdocs/luci-static/resources/view/homeproxy/client.js`

- [ ] **Step 1: Routing 页加 TUN/UDP NAT 控件（proxy_mode tun/tproxy 相关时显示）**

在 `ipv6_support` option 之后追加：

```js
		o = s.taboption('routing', form.ListValue, 'tun_dns_mode', _('TUN DNS mode (1.14)'),
			_('Leave empty to keep current behavior. hijack/native lets sing-box manage platform DNS; may overlap dnsmasq DNS hijack.'));
		o.value('', _('Unset (default)'));
		o.value('disabled', _('Disabled'));
		o.value('native', _('Native'));
		o.value('hijack', _('Hijack'));
		o.depends('proxy_mode', 'redirect_tun');
		o.depends('proxy_mode', 'tun');
		o.rmempty = false;

		o = s.taboption('routing', form.DynamicList, 'tun_dns_address', _('TUN DNS addresses (1.14)'));
		o.datatype = 'ipaddr';
		o.depends({'proxy_mode': /^((?!custom).)+$/, 'tun_dns_mode': /[\s\S]/});
		o.modalonly = true;

		o = s.taboption('routing', form.ListValue, 'udp_mapping', _('UDP NAT mapping (1.14)'));
		o.value('', _('Default'));
		o.value('endpoint_independent', _('Endpoint independent'));
		o.value('address_dependent', _('Address dependent'));
		o.value('address_and_port_dependent', _('Address and port dependent'));
		o.depends('proxy_mode', 'redirect_tproxy');
		o.depends('proxy_mode', 'redirect_tun');
		o.depends('proxy_mode', 'tun');
		o.rmempty = false;

		o = s.taboption('routing', form.ListValue, 'udp_filtering', _('UDP NAT filtering (1.14)'));
		o.value('', _('Default'));
		o.value('endpoint_independent', _('Endpoint independent'));
		o.value('address_dependent', _('Address dependent'));
		o.value('address_and_port_dependent', _('Address and port dependent'));
		o.depends('proxy_mode', 'redirect_tproxy');
		o.depends('proxy_mode', 'redirect_tun');
		o.depends('proxy_mode', 'tun');
		o.rmempty = false;

		o = s.taboption('routing', form.Value, 'udp_nat_max', _('UDP NAT sessions max (1.14)'));
		o.datatype = 'uinteger';
		o.depends('proxy_mode', 'redirect_tproxy');
		o.depends('proxy_mode', 'redirect_tun');
		o.depends('proxy_mode', 'tun');
```

（若 options 位于 custom 模式下的 `routing` 段子表单，使用对应 subsection 的 `taboption` 变量；实际 anchor 以实现时页面结构为准。）
